# 🤟 Levora - AI Sign Language Communication Assistant

Levora bridges the communication gap between deaf/mute users 
and hearing people using AI, camera-based gesture recognition, 
speech recognition, and text-to-speech technology.

## ✨ Features

- 🤟 **Sign → Speech** — Detects hand signs and converts to voice
- 🎤 **Speech → Sign** — Converts speech to sign language animations  
- 📚 **Learn Signs** — Practice sign language with AI feedback
- 🆘 **Emergency SOS** — Sends GPS location alert to emergency contacts
- 💬 **Chat & Video Call** — Real-time sign language chat and video calls

## 🛠️ Built With

- Flutter (Dart)
- Firebase (Auth + Firestore)
- TensorFlow Lite / MediaPipe
- Google Speech API
- Agora (Video Calls)
